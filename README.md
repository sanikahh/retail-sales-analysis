# Retail Sales & Profitability Analysis

## Project Overview
This project analyses retail sales data to understand revenue, profitability, product performance and regional trends using Excel and SQL.

## Business Objectives
- Identify the highest-performing product categories.
- Compare sales and profit across regions.
- Examine monthly sales trends.
- Identify products or categories with low or negative profitability.
- Recommend practical business improvements based on the findings.

## Tools Used
- Microsoft Excel
- SQL (MySQL)

## Dataset
**Dataset name:** Sample Superstore

**Source:** [Tableau Public — Sample Superstore Dataset](https://public.tableau.com/app/sample-data/sample_-_superstore.xls)

**File used:** `sample_-_superstore.xls`

**Description:** The dataset contains sample retail order information, including order dates, customer and product details, sales, quantity, discount and profit. It is used to practise data cleaning, sales analysis and profitability analysis.

**Note:** This is fictional sample retail data intended for learning and analysis, not real company transaction data.

The dataset contains order, customer, product, sales, discount and profit information. See the source for its exact fields and licence.
